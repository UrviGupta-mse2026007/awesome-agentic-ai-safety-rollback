# GitHub Implementations

This document contains open-source GitHub repositories relevant to **Safety and Rollback Mechanisms for Objective Misinterpretation in Agentic AI Systems**.

These implementations provide practical frameworks, benchmarks, and environments for developing, evaluating, monitoring, and securing AI agents.

---

# 1. AgentDojo

**Repository:**
https://github.com/ethz-spylab/agentdojo

**Purpose:**
AgentDojo is a dynamic environment for evaluating attacks and defenses for LLM agents.

It focuses particularly on:

* Prompt injection
* Indirect prompt injection
* Agent security
* Tool-use safety
* Defensive mechanisms

**Relevance to this project:**

Objective misinterpretation can occur when an AI agent receives malicious or conflicting instructions from external data.

AgentDojo can be used to test whether an agent:

* Preserves the original user objective
* Rejects malicious instructions
* Safely uses tools
* Avoids unintended actions

**Research Paper:**
https://arxiv.org/abs/2406.13352

# 2. Agent-SafetyBench

**Repository:**
https://github.com/thu-coai/Agent-SafetyBench

**Purpose:**
Agent-SafetyBench provides an implementation for evaluating the safety of LLM agents in interactive environments.

It focuses on multiple categories of safety risks and agent failure modes.

**Relevance to this project:**

The implementation can be used to evaluate:

* Unsafe agent behavior
* Objective-following failures
* Agent interactions
* Multi-step execution
* Safety risks

It is useful for testing whether an agent continues to behave safely when operating autonomously.

**Research Paper:**
https://arxiv.org/abs/2412.14470

---

# 3. ToolEmu

**Repository:**
https://github.com/ryoungj/ToolEmu

**Purpose:**
ToolEmu is a framework for identifying risks associated with LLM agents that use external tools.

It provides environments and evaluation scenarios for studying potentially risky tool-use behavior.

**Relevance to this project:**

Tool use increases the potential impact of objective misinterpretation.

An agent may:

* Call the wrong tool
* Perform an unintended operation
* Cause unexpected side effects
* Execute actions based on an incorrect interpretation

ToolEmu can therefore help evaluate safety mechanisms before agents are deployed in real-world environments.

**Research Paper:**
https://arxiv.org/abs/2309.15817

---

# 4. InjecAgent

**Repository:**
https://github.com/uiuc-kang-lab/InjecAgent

**Purpose:**
InjecAgent provides an implementation and benchmark for evaluating indirect prompt injection attacks against tool-integrated LLM agents.

**Relevance to this project:**

Indirect prompt injection is directly related to objective misinterpretation.

An agent may encounter external content containing malicious instructions and incorrectly follow those instructions instead of the original user objective.

This repository can be useful for evaluating:

* Instruction conflicts
* Objective preservation
* Tool-integrated agents
* Prompt injection vulnerabilities
* Agent security

**Research Paper:**
https://arxiv.org/abs/2403.02691

**Repository:**

AI Safety Gridworlds provides environments for studying fundamental AI safety problems.

The environments include scenarios related to:

It provides controlled environments for studying objective misinterpretation and specification failures.

# 6. LangGraph

**Repository:**
https://github.com/langchain-ai/langgraph

**Purpose:**
LangGraph is a framework for building stateful and long-running AI agent applications.

**Relevance to this project:**

Stateful workflows are particularly useful for implementing safety and rollback mechanisms.

An agent workflow can include states such as:

```text
User Objective
      ↓
Objective Validation
      ↓
Planning
      ↓
Safety Check
      ↓
Checkpoint
      ↓
Action Execution
      ↓
Monitoring
```

If unsafe behavior is detected, the workflow can be interrupted and redirected to a recovery state.

Potential safety features include:

* Checkpoints
* Human approval
* State tracking
* Execution interruption
* Error recovery

**Repository:**
https://github.com/guardrails-ai/guardrails

**Purpose:**
Guardrails AI provides tools for validating and controlling outputs generated by AI systems.

**Relevance to this project:**

Guardrails can help validate an agent's output before it becomes an action.

Possible applications include:

* Output validation

A safety layer can check whether a proposed action violates constraints before allowing the agent to execute it.
